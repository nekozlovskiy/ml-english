# Политика конфиденциальности — Grady (ML English)

_Дата вступления в силу: 3 июля 2026 г._

Grady («ML English», далее — «Приложение») — бесплатное приложение для изучения профессионального английского. Мы придерживаемся принципа минимума данных.

## Коротко

- **Приложение не собирает персональные данные.** Аккаунт и регистрация не требуются.
- **Прогресс хранится локально**, в приложении или в хранилище браузера.
- **Нет рекламы, аналитики и трекинга.** Мы не передаём и не продаём данные третьим лицам.

## Какие данные обрабатываются

### Прогресс обучения (только на устройстве)
Очки опыта, серия дней, пройденные уроки, карточки, избранные фразы и настройки сохраняются локально в хранилище приложения. Эти данные **не отправляются на серверы** и доступны только вам. Вы можете вручную экспортировать резервную копию в настройках и полностью удалить все данные, сбросив прогресс или удалив Приложение.

### Уведомления
Ежедневные напоминания (если вы их включили) планируются локально на устройстве. Серверные push-уведомления не используются.

### Сеть
Веб-версия размещена на GitHub Pages. При открытии сайта GitHub сохраняет IP-адрес посетителя в целях безопасности. Grady не передаёт GitHub учебный прогресс. Подробнее — в [документации GitHub Pages](https://docs.github.com/en/pages/getting-started-with-github-pages/what-is-github-pages).

## Дети

Приложение не предназначено специально для детей и не собирает сознательно данные детей.

## Изменения

Будущие версии могут добавить необязательные функции — например, синхронизацию прогресса между устройствами или анонимные отчёты о сбоях. Они будут включаться только с вашего согласия, и эта политика будет соответствующим образом обновлена.

## Контакты
