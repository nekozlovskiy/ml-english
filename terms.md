# Условия использования — Grady (ML English)

Приложение предоставляет учебные материалы по профессиональному английскому для аналитиков данных и специалистов в области машинного обучения. Оно предназначено для образовательных целей и не гарантирует какого-либо результата обучения, прохождения собеседований или трудоустройства.
